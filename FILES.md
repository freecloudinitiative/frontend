# FILES — Where Code Live

## Root

| File                 | What                                                                                |
| -------------------- | ----------------------------------------------------------------------------------- |
| `package.json`       | Dependencies, npm scripts (`dev`, `build`, `test`, `lint`).                         |
| `package-lock.json`  | Lockfile — exact dependency versions.                                               |
| `vite.config.ts`     | Vite config: React plugin, path alias `@/` → `src/`.                                |
| `tsconfig.json`      | Root TypeScript config. References app + node configs.                              |
| `tsconfig.app.json`  | Browser TypeScript config (strict, bundler module resolution).                      |
| `tsconfig.node.json` | TypeScript config for Vite config file itself.                                      |
| `tsconfig.test.json` | TypeScript config for Vitest test files.                                            |
| `tailwind.config.js` | Tailwind CSS v4 config (content paths).                                             |
| `postcss.config.js`  | PostCSS: Tailwind + autoprefixer.                                                   |
| `.oxlintrc.json`     | oxlint rules config.                                                                |
| `index.html`         | HTML entry point. Loads `/theme-init.js`, `/config.js`, then Vite's `src/main.tsx`. |
| `nginx.conf`         | Production nginx config. Serves `dist/`. Proxies `/api/*` and `/ws/*`.              |
| `Dockerfile`         | Multi-stage: node build → nginx:alpine runtime.                                     |
| `.env.example`       | All env vars with inline docs.                                                      |
| `.dockerignore`      | Excludes `node_modules`, `dist`, dev files from Docker context.                     |
| `.gitignore`         | Excludes `dist/`, `node_modules/`, `.env`.                                          |
| `INFO.md`            | High-level project notes.                                                           |

## src/lib/

| File                 | What                                                                                                                                                                          |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `axios.ts`           | Shared axios instance. Request interceptor: injects Bearer token, strips Content-Type for FormData. Response interceptor: clears token on 401, fires `fci:auth-unauthorized`. |
| `apiError.ts`        | `getApiErrorMessage`, `getApiErrorCode`, `getApiErrorRequestId`. Parses backend error envelopes.                                                                              |
| `apiResource.ts`     | `createResourceApi`: factory for CRUD API functions (list/get/create/remove/patch/updateSettings).                                                                            |
| `oidc.ts`            | `getOidcConfig()`: builds OIDC config from `runtimeConfig`. Returns `null` when auth disabled.                                                                                |
| `runtimeConfig.ts`   | `getRuntimeConfig()`: merges `window.__FCI_CONFIG__` and Vite env vars. `assertValidProductionConfig()` throws on invalid prod URLs.                                          |
| `queryFactory.ts`    | `createResourceHooks`: factory for list/detail/create/remove/updateSettings React Query hooks.                                                                                |
| `websocket.ts`       | `TerminalWebSocket` class: WebSocket lifecycle, exponential backoff reconnect, send queue. `buildTerminalWsUrl(ceId)`.                                                        |
| `format.ts`          | Date/number/bytes formatters used across the UI.                                                                                                                              |
| `theme.ts`           | Theme CSS variable definitions for each of the 5 TUI themes.                                                                                                                  |
| `tui-theme.ts`       | Maps theme IDs to Recharts colour palettes.                                                                                                                                   |
| `mockServiceData.ts` | Static service metadata (names, slugs, status colours) shared across dashboard.                                                                                               |
| `useEntityForm.ts`   | Generic form state hook: tracks values, validation errors, dirty state.                                                                                                       |

## dist/

Build output from `npm run build`. Not committed. Served by nginx in production.

Chunks named after the route/component they belong to (e.g., `ComputeEngineDetailPage-*.js`). Vendor libraries split into separate chunks (`vendor-core`, `vendor-monaco`, `vendor-terminal`, `vendor-charts`, `vendor-query`).
